# KubynoHtmlEditor

Editor HTML vizual pentru contracte și formulare, cu formatare și inserare de placeholders, destinat rapoartelor HTML din Nexus ERP.

## Skill inclus

Acest repository include skill-ul `skill-nexus-html-report`, util pentru creare, conversie și redesign de rapoarte HTML compatibile Nexus ERP.

- Skill: `skill-nexus-html-report/SKILL.md`
- Referințe câmpuri exemplu: `skill-nexus-html-report/references/fields_rap1697.md`

## Template-uri

- Prima pagină ofertă comercială Nexus: `templates/oferta_belfix_pagina1_nexus.html`
